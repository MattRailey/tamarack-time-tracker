Import

Bring in time entries from Clockify, split and attach invoice PDFs exported from QuickBooks, or import exact invoice amounts from a QuickBooks invoice-list CSV.

Export your Clockify time entries as CSV (Clockify → Reports → Detailed → Export → CSV), then load that file here. Nothing is written until you review the preview and confirm.

Column names are matched flexibly (Project, Client, Description, Start Date, Start Time, End Date, End Time, Duration) but Clockify has changed its export format before — check the preview table against your actual CSV before confirming, especially the first time. Imported entries are marked "not yet invoiced" by default; if this is historical, already-billed work, use the Reports tab right after importing to bulk-mark the whole imported date range as invoiced.

Upload PDF(s) exported from QuickBooks — a single invoice, or a combined batch-print of many invoices back to back — and this splits it into one PDF per invoice, guesses which project each belongs to from the "Bill To" text on the page, and attaches the results directly to those projects (same place shown on the Projects tab, under each project's row). Everything runs in your browser; files go straight to your own Dropbox, nowhere else.

Data file

Connect to Dropbox on every device (desktop included) so they all read and write the exact same data. Every save re-checks nothing changed since you last loaded it and warns you instead of silently overwriting.

Connect to Dropbox — use this on every device

Connected to Dropbox

Signs in with your Dropbox account and stores the data file in a private app folder Dropbox creates for this app — it doesn't touch the rest of your Dropbox. If a local file is already loaded on this device when you click Connect, its data is copied over automatically so you don't lose anything.

Automatic backups

A dated, never-overwritten snapshot of your whole data file is saved automatically to a private /backups folder in this app's Dropbox space — the first time you open the app or save something each day. On top of that, Dropbox keeps its own version history of every save to the main file, so a bad edit is always recoverable two ways.

Local file (older method, desktop Chrome/Edge only)

Kept as a fallback — a file only readable on this one computer, not synced anywhere unless you manually keep it in your Dropbox folder (and even then, only one computer at a time). Connecting to Dropbox above is the option to use now.
